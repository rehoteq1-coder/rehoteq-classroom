REHOTEQ CLASSROOM — MASTERCLASS BACKLOG
=======================================
This file is NOT loaded by the app. Nothing here is downloaded to a learner's
phone. It is drafted content waiting to be switched on.

The Masterclass currently ships M1 and M2 (6 lessons, 2 quizzes, ids 100-105).
Everything below is written and ready. Ids 106-113 are RESERVED for it, in the
order shown, so adding it later cannot disturb anyone's saved progress.

HOW TO SWITCH A MODULE ON
-------------------------
1. index.html — paste the module's lesson lines at the END of var M_LESSONS=[...].
   Append only. Never insert above an existing lesson: saved progress is stored
   as a position in this list, so inserting shifts everyone onto the wrong lesson.
2. index.html — paste the matching quiz into var M_QZ={...}, before the closing };
   Remember the comma after the previous quiz.
3. admin.html — raise TRACKS.Masterclass.total to the new lesson count.
4. sw.js — bump the cache version, then re-upload.

Add whole modules at a time. A module whose quiz is missing still works, but
learners see lessons they cannot be tested on.

WHEN TO MOVE TO A JSON FILE INSTEAD
-----------------------------------
If the Masterclass grows past roughly 10 lessons, index.html starts carrying
more text than a first paint needs. At that point move BOTH tracks into
content.json, fetch it once, and let the service worker cache it. The track
structure in index.html already supports that: only the two lessons/quizzes
arrays would move. Do not do this earlier; one file is cheaper than two
round-trips on a weak network.

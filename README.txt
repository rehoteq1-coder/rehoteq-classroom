REHOTEQ CLASSROOM - HOW TO PUT IT ONLINE (GitHub Pages)

1. On GitHub create a public repository, for example: classroom
2. Add file > Upload files. Upload ALL 5 files: index.html, sw.js, manifest.json, icon-192.png, icon-512.png
3. Settings > Pages > Deploy from a branch > main > root > Save.
4. Open the link on your phone in Chrome (needs internet the first time). Wait a few seconds.
   The green badge should say "Online - saved for offline".
5. Turn on airplane mode and reopen the app. It should still open and save progress.
6. Install: Chrome menu > Add to Home screen (or Install app).

UPDATING: after you change any file, open sw.js and change v1 to v2 (then v3...). Upload the files again.
TIP: use your own subdomain later (for example classroom.rehoteq.com) by adding a CNAME record.
